Git & GitHub Quick Reference

A scannable guide for version control basics

What is Git?

Git is a local Version Control System (VCS). It tracks changes in your files, saves code history checkpoints, and helps you revert or merge code branches on your computer.

What is GitHub?

GitHub is a cloud-based platform. It hosts your remote Git repositories online, allowing teams to collaborate, back up local work, manage issues, and review code.

Essential Git Commands

Command Description
git init Initializes a new local Git repository in the current folder.
git status Shows untracked, modified, or staged files.
git add <file> Stages a specific file. Use git add . to stage all changes.
git commit -m "msg" Saves staged changes to your history with a descriptive message.
git branch -M main Renames your default branch to "main".
git log Displays your repository's commit history details.

Standard Remote Workflow

To hook up a local repository to GitHub and publish your code, run these terminal commands in order:

# 1. Initialize local repository
git init

# 2. Stage your files
git add .

# 3. Commit your changes
git commit -m "Initial commit"

# 4. Point to your remote GitHub repository URL
git remote add origin https://github.com

# 5. Push your code up to the server
git push -u origin main

Collaboration Commands

Command Description
git clone <url> Downloads an existing remote repository onto your computer.
git pull Fetches and downloads updates from GitHub directly into your current branch.
git checkout -b <name> Creates and immediately switches to a new feature branch.
git merge <branch> Combines another branch's changes into your active branch.
